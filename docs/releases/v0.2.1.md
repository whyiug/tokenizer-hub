# Tokenizer Hub v0.2.1

This patch release fixes the Vercel Python runtime dependency manifest used by v0.2.0.

## Fixed

- Declare Jinja2 in the committed `pyproject.toml` and `uv.lock` so structured prompt rendering starts correctly on Vercel.
- Add a regression test that verifies the deployment manifest includes the prompt renderer dependency.

All v0.2.0 model, tokenizer, and structured prompt features are unchanged.
